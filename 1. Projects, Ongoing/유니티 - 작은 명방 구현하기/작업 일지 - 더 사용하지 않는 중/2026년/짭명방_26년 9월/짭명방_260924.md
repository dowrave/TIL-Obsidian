## 메인메뉴 씬 -> 타이틀 씬 전환 시각 효과 처리
- 타이틀 씬의 도형이 카메라의 중앙에 오면서 작아지는 효과를 구현하려고 함
- 크게 2가지 방법이 있을 듯 : 도형을 움직이든가, 카메라를 움직이든가.

- AI에게 물어봤는데 **도형을 움직이는 방법을 추천**했음.
1. `Camera` 설정이 `Orthographic`이라면 카메라를 물려도 도형이 작아지지 않으며, `Perspective`이더라도 **원하는 만큼 작게 만들려면 카메라 이동 거리와 FOV를 역산**해야 함
2. 부수 효과가 도형에만 격리됨 - **카메라를 움직이면 다른 오브젝트들도 다 고려**해야 함
3. 편의성 측면(눈으로 테스트하면서 인스펙터에서 값을 맞추는 방식)에선 두 방식 모두 큰 차이는 없음
### 구현
- 전체 흐름
#### 도형 위치 및 스케일 전환
- 카메라 정중앙으로 도형을 이동시키고 스케일을 줄임
- **`SolidBuilder`의 이름 관련 질문** : 도형 자체에 붙어있는 스크립트. 만드는 역할`Build` 외에도 버텍스 펄스가 돌아가는 코루틴을 관리한다든가, 이제 추가할 위치 / 크기 변경 로직까지 추가되게 됨.
- 그래서 **`SolidController`로 이름 변경**.

- 구조 자체가 아래와 같은 상황이므로
```
SolidRoot(SolidRotator)
- Solid(SolidController)
```
- `SolidRoot`에서는 **위치 이동을 담당하는 스크립트 하나를 추가**한다. `SolidTransition`
	- `Rotator`와는 책임을 구분시키기 위함이다. `Rotator`는 스스로의 회전을 담당했지만 이제 구현할 동작은 외부에서 트리거되는 위치 전환이 들어가기 때문이다.

- `SolidTransition`
```cs
using System.Collections;
using UnityEngine;

public class SolidRootTransition : MonoBehaviour
{
    [SerializeField, Tooltip("스케일이 적용될 자식 Solid의 Transform")]
    private Transform _solidVisualTransform;

    [SerializeField, Tooltip("전환 시 이동할 목표 로컬 위치(카메라 정중앙에 해당)")]
    private Vector3 _transitionTargetLocalPosition = Vector3.zero;

    [SerializeField, Tooltip("전환 후 크기 배율. 1 = 현재 크기 그대로, 1보다 작으면 축소")]
    private float _transitionTargetScale = 0.85f;

    [SerializeField, Tooltip("전환 시간")] 
    private float _transitionDuration = 2f;

    public void PlayTransitionEffect()
    {
        StartCoroutine(TransitionRoutine(_transitionDuration));
    }

    private IEnumerator TransitionRoutine(float duration)
    {
        Vector3 startPos = transform.localPosition;
        Vector3 startScale = _solidVisualTransform.localScale;
        Vector3 endScale = startScale * _transitionTargetScale;

        float t = 0f;
        while (t < duration)
        {
            t += Time.deltaTime;
            float k = Mathf.SmoothStep(0f, 1f, Mathf.Clamp01(t / duration));

            transform.localPosition = Vector3.Lerp(startPos, _transitionTargetLocalPosition, k);
            _solidVisualTransform.localScale = Vector3.Lerp(startScale, endScale, k);

            yield return null;
        }

        transform.localPosition = _transitionTargetLocalPosition;
        _solidVisualTransform.localScale = endScale;
    }
}
```

> 도형의 최종 위치는 플레이 중에 눈으로 맞춤. 
> - 배율 : 70%
> - 위치 : (0, -2, 0)
> - 전환 시간 : 2초


## 기타 팁

>[!note]
>Play 중에 마음에 드는 각도를 찾고, 인스펙터의 Copy Component as Value를 하고, Stop 후 Paste를 하면 여러 번 테스트할 필요 없이 한 번에 마음에 드는 구도를 잡을 수 있음.
>- 2년 넘게 작업했는데 이런 생각은 1도 못했네;

>[!note]
>클래스의 이름을 바꿀 때, 코드의 수정은 IDE에서 하되 **파일 이름의 수정은 유니티에서 해야 참조가 깨지지 않는다.** IDE에서 파일 이름을 바꿈면 `.meta` 파일의 GUID 참조가 깨짐.
>- 무심코 지나치기 쉬운 포인트라서 한 번 더 기록해둠.

>[!note]
>필드의 이름을 바꾸고 싶은데 데이터가 날아갈 게 걱정된다면 `[FormerlySerializedAs("FormerFieldName")]`이라는 어트리뷰트를 붙이면 됨.
>- 귀찮긴 한데 데이터를 전부 다시 할당하는 것보단 낫다. AI로 해도 되고.
