### 로딩 게이지 무한 반복 & 씬 전환 대기 화면 나타나게 하기

- 원인
	- 구조가 애초에 이상했음. 
```cs
private void Start()
{
	InitializeFirstScreen();

	_loadingGauge.Completed += HandleLoadingGaugeCompleted;

	_currentLayout = _mainLayout;
}

public void BeginSessionTransition(int slotId)
{
	_pendingSlotId = slotId;
	_loadingGauge.Show();
	_loadingGauge.Play();
}

// 로딩 게이지 완료 후, 메인메뉴 씬 진입하는 동작
private void HandleLoadingGaugeCompleted()
{
	_currentLayout.Hide();
	BeginSessionTransition(_pendingSlotId); // ????
}
```
로딩 게이지가 완료되면 다시 로딩을 시작하는 구조라서 그랬다. 

```cs
// 로딩 게이지 완료 후, 메인메뉴 씬 진입하는 동작
public void BeginSessionTransition(int slotId)
{
	_currentLayout.Hide();
	_pendingSlotId = slotId;
	_loadingGauge.Show();
	_loadingGauge.Play();
}

// 로딩 게이지 완료 후, 메인메뉴 씬 진입하는 동작(실제 전환 로직)
private void HandleLoadingGaugeCompleted()
{
	GameManagement.Instance.SceneLoader.LoadMainMenu();
}
```
으로 바꾸고 테스트.

### 다른 레이아웃 사라지게 하기
```cs
// TitleManager.cs
public void BeginSessionTransition(int slotId)
{
	_currentLayout.Hide(); // 이거 추가
	_pendingSlotId = slotId;
	_loadingGauge.Show();
	_loadingGauge.Play();
}
```
직전에는 `HandleLoadingGaugeCompleted`에 추가했는데, 그러면 로딩 게이지가 사라진 다음에 레이아웃이 사라짐.
