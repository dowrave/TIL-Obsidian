## 메인메뉴 씬 진입 시 로딩 화면 동작

### 상황 분석
- 메인메뉴 씬 진입하면 메인메뉴의 레이아웃이 등장한 다음 로딩 화면이 서서히 페이드아웃됨
- 근데 **로딩 화면이 메인메뉴 씬의 레이아웃을 가려야 하는데, 메인메뉴 씬보다 더 뒤에 레이아웃이 있음**

코드상 아래와 같으며
```cs
// SceneLoader.cs
private void ShowLoadingScreen(bool isStageLoading)
{
	if (loadingScreenPrefab == null) return;

	GameObject loadingObj = Instantiate(loadingScreenPrefab);

	// ...
}
```

하이어라키상 `LoadingScreen` 자체가 별도의 캔버스를 가지며, `DontDestroyOnLoad`의 최상단에 나타남.

### 해결
- **`LoadingScreen` 캔버스의 `Sort Order`를 `1`로 높였음**

- [[유니티 - 렌더링 순서(캔버스, 하이어라키)]]



## 기타 이슈 수정

### 스테이지 씬 진입 시 SessionData 관련 NRE 이슈
- 이제 귀찮으니 NRE로 줄여서 부름. null 예외 처리 오류.
1. **`SessionData`는 `SessionDataManager`이므로 프로퍼티 이름 `SessionDataManager`로 변경.** 
	- 다른 것들은 딱히 `Manager`를 붙이지 않았는데 `SessionData`라고 써놓으니까 진짜로 `GameSession`에 `SessionData`를 꺼내놓은 것 같다는 인상이다. 이것만큼은 `Manager`를 쓰기로 함.
2. **왜 null임?**
	- 상황
		- (`DontDestroyOnLoad`도 `DDOL`로 줄여서 부름)
		- 씬 전환 상황에서 `UserSquadManager`의 `OnDestroy`가 동작함. 문제는 얘는 DDOL인 `GameSession`의 자식이라는 것.
	- 해결
		- **해결 자체는 구독 해제 메서드에서 `null` 체크만 해주면 됨**
		- **하지만 원인을 알고 싶다.** 왜 발생하는 걸까? 디버깅 로그로 추적해봄.

```cs
// 메인메뉴 씬
[Squad] Start id=-118240 scene=DontDestroyOnLoad
UnityEngine.Debug:Log (object)
UserSquadManager:Start () (at Assets/_Scripts/Core/Managers/GameSession/UserSquadManager.cs:26)

// 스테이지 씬
[Squad] Start id=101374 scene=StageScene
UnityEngine.Debug:Log (object)
UserSquadManager:Start () (at Assets/_Scripts/Core/Managers/GameSession/UserSquadManager.cs:26)
[Squad] OnDestroy id=-123466 scene=StageScene, sessionData null? True
UnityEngine.Debug:Log (object)
UserSquadManager:OnDestroy () (at Assets/_Scripts/Core/Managers/GameSession/UserSquadManager.cs:165)
```

즉 스테이지 씬의 다른 인스턴스에서 한 번 더 Start와 OnDestroy가 실행되려 했다는 것. 

- 해결
	- **`StageScene`에 `GameSession`이 남아 있었다.** 삭제 후 잘 동작하는지 다시 테스트.
	- `OnDestroy`의 `null` 체크도 유지한다. 있어서 나쁠 거 없음.
