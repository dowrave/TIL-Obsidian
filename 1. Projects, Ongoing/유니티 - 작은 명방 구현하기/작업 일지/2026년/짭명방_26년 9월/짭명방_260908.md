## 이슈 수정

### 2번째 세션 진입부터 나타나는 `NullReferenceException`
- [[유니티 - 씬 전환과 오브젝트 파괴]]
	- 요약) (Single 모드 기준) 새로운 씬의 로드 완료 후 이전 씬의 모든 오브젝트를 파괴함 - 그래서 이전에 열었던 씬으로 다시 돌아가는 개념이 아니라 새로운 씬을 여는 개념임
- 원인) **`GameSession`이 세션을 나갔을 때 파괴되지 않음(파괴 메서드는 있으나 실행되지 않고 있음)**
- 해결) ~~`GameSession`을 `GameManagement`의 어딘가에서 잡고 있어야 함~~
	- `GameSession`이 종료되는 시점에 없애야 함
```cs
// GameSession.cs의 종료 메서드
public static void Teardown()
{
	if (Instance == null) return;
	Destroy(Instance.gameObject);
	Instance = null;
}
```
- [[유니티 - 싱글턴 메서드 - static vs 일반]]
	- 왜 싱글턴 오브젝트의 메서드인데도 `static`으로 선언했는지 궁금해서 정리.
	- 싱글턴의 메서드는 대부분 일반 메서드로 쓰지만, `GameSession.Instance` 체크를 이 메서드 호출마다 일일이 하게 하고 싶지 않을 경우 이렇게 쓴다.

```cs
// 호출은 이렇게만 하면 됨
public void LoadTitle() 
{
	if (isFadeInCompleted) isFadeInCompleted = true;
	GameManagement.Instance.CurrentSlot = -1; // 세이브 슬롯 인덱스 초기화
	GameSession.Teardown(); // 게임 세션 오브젝트 파괴
	LoadScene(SceneType.Title); 
}
```
> 사실 이거 한 줄 추가하면 되는데 괜히 빙 돈 느낌도 있다. 그래도 모르겠는 건 정리해두는 게 좋으니까..

#### 추가 이슈 : 이벤트 구독 해제 이슈
- `GameSession`을 참고해서 들어가는 오브젝트들의 구독 해제 과정에서 `GameSession`이 이미 사라졌기 때문에 `NRE`가 발생함
```cs
private void OnDestroy()
{
	GameSession.Instance.Test.stageCleared -= InitializeStageButtons;
}
```

기존에는 `GameSession`이 유지됐기 때문에 위 코드가 동작했지만, 이젠 `GameSession`이 먼저 사라진 다음에 `OnDestroy()`가 동작해서 이런 이슈가 발생함.

하지만 씬 전환 과정에서 위 코드가 동작할 필요는 없다. 다 사라지니까.

**따라서, `(GameSession.Instance == null) return;` 조건만 추가해주면 됨.** 일일이 달아두는 게 불편하다면 이벤트로 구현해도 된다. 이 경우는 오류 발생 지점이 3곳이므로 그냥 일일이 방어 코드를 달아둠.
```cs
private void OnDestroy()
{
	if (GameSession.Instance == null) return;
	GameSession.Instance.Test.stageCleared -= InitializeStageButtons;
}
```
