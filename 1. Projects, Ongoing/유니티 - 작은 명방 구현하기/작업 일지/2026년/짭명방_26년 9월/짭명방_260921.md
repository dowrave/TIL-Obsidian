### VertexPulse
- 현재 : 일시적으로 점이 커졌다가 작아지는 게 눈에 보임. 즉, **잠시 더 크게 반짝이는 것처럼 보이는 게 아니라 크기 변화로 보인다**는 것
- 원하는 내용 : 현재의 패턴을 유지하되 커지는 효과보다는 빛이 밝아지는 효과로 보이게 하고 싶음

#### 원인과 작업 방향
- 실제로 스크립트 단위에서 크기를 바꾸고 있지만, 밝기 개념이 바뀌진 않고 있음.

> VertexPulse - View Genereated Shader로 셰이더를 넣었는데 중간에 멈춘 것까지 감안해도 거의 5분의 생각 시간이 들어갔다. 계속 그러다 보니까 아예 대화창을 변경했음.

- "멀리서 보는 불빛"에 가깝기 때문에, 점광원보다는 텍스쳐를 써야 할 듯.


#### 작업 과정과 수정 사항

##### 1. VertexPulse 수정 중, 빌보드 파트가 날아갔음. 
- `LateUpdate`에 방향 = 카메라 방향으로 보게끔 다시 설정

// 빌보드 : 펄스 여부와 관계 없이 매 프레임 카메라와 같은 회전
if (_targetCamera != null)
	transform.rotation = _targetCamera.transform.rotation;

##### 3. 텍스쳐 추가 시 - 펄스가 나타나지 않음
- 원 메쉬를 만들지만, UV를 넣지 않음(`TitleSolid.BuildCircleMesh()`)
- **UV가 없는 경우 모든 정점의 UV는 (0, 0)이 된다. 이 경우, `Sample Texture 2D`는 텍스쳐 좌하단의 1픽셀만 읽게 됨.**
- 원 메쉬에 UV를 추가하는 것으로 수정 가능.
	- 중심 : (0.5, 0.5)
	- 가장자리 : 단위원 좌표를 0 ~ 1 사이로 옮긴 값
```cs
// UV 항목들이 추가됨
public static Mesh BuildCircleMesh(int segments = 24)
{
	var mesh = new Mesh { name = "PulseCircle" };
	var verts = new Vector3[segments + 1];
	var uvs = new Vector2[segments + 1]; 
	var tris = new int[segments * 3];

	// 중심점
	verts[0] = Vector3.zero; 
	uvs[0] = new Vector2(0.5f, 0.5f);

	// 가장자리 정점 - 위치는 단위원, UV는 [-1, 1] 좌표를 [0, 1] 좌표로 변환
	for (int i = 0; i < segments; i++)
	{
		float angle = (float) i / segments * Mathf.PI * 2f;
		float cos = Mathf.Cos(angle);
		float sin = Mathf.Sin(angle);
		verts[i + 1] = new Vector3(cos, sin, 0f);
		uvs[i + 1] = new Vector2(cos * 0.5f + 0.5f, sin * 0.5f + 0.5f);
	}

	// 중심 -> 위 -> 오른쪽 순(= 시계 방향)으로 선들을 잇는다. 만들어진 도형은 +Z를 본다.
	for (int i = 0; i < segments; i++)
	{
		tris[i * 3] = 0;
		tris[i * 3 + 1] = (i + 1) % segments + 1;
		tris[i * 3 + 2] = i + 1;
	}

	// 중심 -> 위 -> 오른쪽 순(= 시계 방향)으로 선들을 잇는다. 만들어진 도형은 -Z를 본다.
	// for (int i = 0; i < segments; i++)
	// {
	//     tris[i * 3] = 0;
	//     tris[i * 3 + 1] = i + 1;
	//     tris[i * 3 + 2] = (i + 1)  % segments + 1;
	// }

	mesh.vertices = verts;
	mesh.uv = uvs; 
	mesh.triangles = tris;
	mesh.RecalculateNormals();
	mesh.RecalculateBounds();
	return mesh; 
}
```

##### 4. 밋밋한 펄스 효과
- 텍스쳐 추가 후, `baseBrightness`에서는 텍스쳐 느낌이 잘 살아있는데 `maxBrightness`에서는 텍스쳐 추가 전과 비슷한, 밋밋한 단색의 도형이 되는 느낌이 있음
	1. `Blending Mode` : `Alpha` -> `Additive` 
	2. **중심부를 강조하는 커브를 추가**함
		- 코어 부분을 따로 뽑아서 중심을 더 밝게, 가장자리는 상대적으로 덜 밝게 처리하는 구현.
