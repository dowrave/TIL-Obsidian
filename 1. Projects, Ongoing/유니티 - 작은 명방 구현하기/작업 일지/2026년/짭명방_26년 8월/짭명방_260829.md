## 타이틀 씬 기능 완성하기

### 시작 / 계속하기에 따른 기능 구분하기

- 공통 
	- 슬롯의 클릭 자체는 해당 슬롯의 선택 여부만을 결정한다.
	- 곧바로 진입 여부로 이어지지 않음.
	- 별도의 확인 버튼과 삭제 버튼도 구현 ㄱ

- 시작하기
	- 빈 슬롯 : 바로 진입
	- 이미 있는 슬롯 : 삭제 여부를 묻는 패널이 나타남
- 계속하기
	- 빈 슬롯 : 새로운 데이터를 만들고 진입할지를 묻는 패널이 나타남
	- 이미 있는 슬롯 : 바로 진입

이 때 **"시작하기" 상태인지 "계속하기" 상태인지 여부**를 UI 요소인 `TitleSaveSlotLayout`에서 가지면 안되고, **상위 객체(매니저 / 컨트롤러)가 해당 정보를 갖고 있는 편이 좋다.** 

- UI 요소가 2가지 책임을 갖기 때문이다.
	1. 슬롯 자체를 갖고 클릭을 받는 책임
	2. 현재 모드를 아는 책임(상위 로직의 책임)

> 이 경우 `TitleManager`나 `SaveSlotManager`에서 해당 정보를 가지고 있으면 좋음. 









## 기타 이슈

### 1:1 비율이 아닐 때 스프라이트 깨지는 문제
- [[Unity - 9슬라이싱 스프라이트]]로 정리.
- `OperatorSlot`에서도 비슷한 이슈가 있었는데, `512 x 512`로 만든 선택된 상태를 나타내는 인디케이터를 실제로 x축 / y축으로 늘어난 UI에 대해 사용하려고 하면 해당 방향으로 이미지가 늘어난 형태로 나타난다.

![[Pasted image 20260829120353.png]]

- 원래는 상하좌우 테두리 두께가 다 동일한데, x축으로 긴 스프라이트는 이미지가 늘어지는 현상이 있음

#### 9슬라이싱 스프라이트
- 유니티에선 위 이슈를 해결하기 위해 `9-Slicing`이라는 기능을 제공함.

![[Pasted image 20260829120649.png]]
- A, C, G, I는 크기가 변경되지 않음
- B, H는 수평으로 스트레치 / 타일
- D, F는 수직으로 스트레치 / 타일
- E는 수평, 수직 모두 스트레치 / 타일

##### 설정법
1. 스프라이트 세팅 확인
	- `Mesh Type - Full Rect`으로 선택

2. `Sprite Editor`
	- 스프라이트의 테두리를 정의함. 
	- 위 이미지처럼 8개의 연두색 점을 이용해 경계를 잡아준다.
	- `Border`로 수치를 입력할 수도 있음.
