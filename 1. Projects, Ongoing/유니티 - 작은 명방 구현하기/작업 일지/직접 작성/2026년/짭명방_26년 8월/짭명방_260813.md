## TitleScene 계속 구현

### 기존 발생했던 이슈
- 씬 뷰에서는 각 버텍스에서 원이 퍼져나가는 게 보이는데 게임 뷰에서는 보이지 않음

#### 원인
```cs
// 반시계 방향, 도형은 -Z축을 보게 된다.
for (int i = 0; i < segments; i++)
{
	tris[i * 3] = 0;
	tris[i * 3 + 1] = i + 1;
	tris[i * 3 + 2] = (i + 1)  % segments + 1;
}
```
- 원을 구성하는 삼각형을 잇는 부분인데, 위 코드는 반시계 방향으로 원을 그린다. 
- **반시계 방향으로 원을 그렸을 때, 도형이 보는 방향은 -Z 축**이 됨.
- 반면 **시계 방향으로 원을 그리면 도형이 보는 방향은 +Z 축**이 된다.
- 따라서 2번째로 그려지는 선과 3번째로 그려지는 선의 순서를 바꾸면 된다.

**카메라의 시선에서 뒷면이 보이는 폴리곤은 아예 그리지 않고 무시**하는 로직이 유니티에 있는데, 이를 `백페이스 컬링`이라고 한다. 

> 예전에 쉐이더 공부할 때 양면 다 렌더링할 수 있는 것도 있었음. 기본 설정은 Front만 렌더링되는 거라고 생각하면 되겠다.
