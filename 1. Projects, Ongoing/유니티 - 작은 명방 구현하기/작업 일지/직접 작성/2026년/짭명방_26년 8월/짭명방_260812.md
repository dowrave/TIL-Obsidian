## 먼저 할 일

### 1. `GetActionableGridPos`가 제대로 들어오지 않는 현상
```cs
// 배치되지 않은 경우 - 현재 위치 / 방향을 계산해서 받음
// gridPosToHighlight = _combat.CurrentActionableGridPos;

if (!Deployment.IsDeployed)
{
	gridPosToHighlight = _combat.GetActionableGridPos();
}
else
{
	gridPosToHighlight = new List<Vector2Int>(_combat.CurrentActionableGridPos);
}

Logger.LogFieldStatus(gridPosToHighlight);
```
- 이 부분은 `CurrentActionableGridPos, GetActionableGridPos()` 등도 엮인 문제라서 같이 해결함 - 정확히 뭐가 어떤 역할을 하는지 이름만 갖고는 구분되지 않음
