#Csharp 

## 표현식Expression
- 평가되면 반드시 값을 만들어낸다.
- 어딘가에 대입하거나, 인자로 넘기거나, 다른 표현식 안에 끼워넣을 수 있다.

```cs
5 + 3 // 8을 만든다
a > b // true / false를 만든다
Pop() // 값을 반환하므로 표현식
c switch { ... } // 값을 만드니 표현식
```

## 문Statement
- 값을 만들지 않고, 동작을 수행한다. 대입할 곳이 없다.

```cs
if (a > b) { ... } // 조건에 따라 분기만 하며, 값이 없음.
for (...) { ... } // 반복만 함
int x; // 선언만 함
break; // 흐름 제어만 함
```

## 구분법 
- **이 코드를 대입할 수 있는가?**
```cs
int x = if (a > b) { ... } // 컴파일 에러 : if 는 "문"이라서 값이 없음
int x = a > b ? 1 : 0; // 삼항 연산자 - 표현식이라서 대입 가능
int x = c switch { ... }; // switch 표현식 - 대입 가능 
```

[[자료구조 - 5. 스택#stack.pop()을 값을 반환하도록 짜는 이유|stack.Pop()]] 같은 경우, 반환값을 일반적으로 가지니까 표현식이다. 다만 반환값이 필요 없는 경우에는 그냥 `Stack.Pop();`처럼 호출만 하는데, 이를 `표현식 문Expression Statement`이라고 해서 표현식 뒤에 세미콜론만 붙여서 문처럼 취급한다. 값을 만들자마자 버리는 식으로.
