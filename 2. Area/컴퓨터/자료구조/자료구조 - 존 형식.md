- **10진수 한 자리를 존 형식으로 표현**하기 위해, 1바이트(8비트)를 한 단위로 사용한다.
- 상위 4비트 존 영역과 하위 4비트 수치 영역으로 구성된다.

```
<< 10진수 한 자리에 대한 표현 >>
  
1 1 1 1 | ㅁㅁㅁㅁ
< 존 >    < 수치 >
```
1. 존 영역에는 항상 1111을 표시한다.
2. 수치 영역은 아래와 같다.
	- `0000` ~ `1001` : 0 ~ 9
	- `1010` : A = 10
	- `1011` : B = 11
	- `1100` : C = 12
	- `1101` : D = 13
	- `1110` : E = 14
	- `1111` : F = 15

- 여러 자리는 위 규칙을 각 자리에 대해 나열하면 된다.
- **부호는 마지막 바이트의 존 영역에서 설정**된다.
	- `+` : `1100` (C)
	- `-` : `1101` (D)

- 예시 (뒷쪽 표기법을 권장)
	- +213 : `11110010 11110001 11000011` = `F2 F1 C3 (16)` 혹은 `0xF2F1C3`
	- -213 : `11110010 11110001 11010011` = `F2 F1 D3 (16)` 혹은 `0xF2F1D3`
