```
StageAndPlayTime

    - StageLabel
    - StageText

    - PlayTimeText
```

이런 구조에서, 상위 컨테이너의 너비는 직접 지정하는가? 아니면 하위 요소들로 계산`Content Size Fitter, CSF`하는가?

## 원칙 : 컨테이너의 역할에 따라 크기 결정 방식이 다르다
- **내용물에 맞춰서 딱 붙어야 하는 컨테이너** 
	- `CSF`로 자식 크기의 합을 자동으로 따라가게 함
- **정해진 공간을 채우고 자식들을 벌려놔야 하는 컨테이너** 
	- 부모 기준으로 `Stretch`, CSF를 걸면 안됨.

위 예제에서 `Stage, PlayTime`은 내용에 딱 맞춰서 붙어야 한다. 라벨 / 텍스트 길이에 따라 그룹 크기가 같이 늘어나거나 줄어들어야 하기 때문이다.

한편, 최상위 컨테이너는 "공간을 차지하는 것" 자체가 목적이다. 그래야 그 안에 UI 요소들을 채워넣을 수 있기 때문에, 여기에 `Content Size Fitter`를 거는 건 권장되지 않음.
