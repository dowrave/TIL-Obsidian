## 개념
- `포인터` 
	- 변수가 저장되는 **메모리의 위치(주소값)를 저장하는 변수**
	- 포인터 변수 P가 변수 A의 주소를 저장하고 있다는 것은, 포인터 변수 P가 변수 A의 위치를 가리키고 있다는 것이다. 포인터 변수를 줄여 포인터라고 한다.

> `C#`의 경우 참조 또한 내부적으로는 포인터로 작동하지만, 개발자가 메모리를 직접 건드려 버그를 내지 못하도록 `C# 컴파일러`가 포인터를 감싸 안전하게 만들었다.
> `C++` 기반 라이브러리`Native Plugin`와 통신하거나 극상의 성능 최적화`unsafe`에 필요한 개념.

## 선언
> `C#`에서는 `unsafe` 블록 내부에서만 포인터 선언이 가능하다.

```cs
unsafe
{
	int* pInt; // int형 변수 주소
	char* pChar; // char형 변수 주소
}
```

## 포인터 연산
```cs
unsafe
{
	int num = 100;
	int* p = &num; // & 연산자 - num의 메모리 주소를 추출해서 p에 저장함
	
	Console.WriteLine(*p); // * 연산자 : p가 가리키는 주소의 값을 읽음
	
	*p = 200; // p가 가리키는 주소 값을 200으로 변경
}
```
### 주소연산자(&)
- 변수 앞에 붙어 해당 변수가 할당된 메모리의 시작 주소를 추출한다.
### 참조연산자(`*`)
- 포인터 변수 앞에 붙어, 포인터가 가리키고 있는 주소로 찾아가 그곳의 실제 값에 접근하거나 수정한다.

## 초기화
- 반드시 올바른 메모리 주소로 초기화하거나, 가리키는 곳이 없을 때는 `null`이나 `IntPtr.Zero`로 추출해야 한다. 
- 초기화하지 않은 주소를 역참조하면 프로그램이 강제 종료된다.
