## 배열Array

### 개념
- **자료형이 같은 자료를 나열**해서 **메모리에 연속으로 저장**해서 만든 자료 그룹.
- `인덱스Index` : 배열 요소를 간단히 구별하기 위해 사용하는 번호

### 1차원 배열
#### 선언
- 배열의 자료형과 이름을 지정한다. 
- 이 단계에서는 메모리가 할당되지 않는다.

```C#
int[] scores;
GameObject[] targets;
```
#### 초기화
- `new` 키워드로 메모리 크기를 할당하거나, 생성과 동시에 값을 지정한다.
```cs
// 크기 지정
int[] scores = new int[5]; // 기본값 0으로 5개가 채워짐

// 값을 지정하며 초기화
int[] scores = new int[] { 10, 20, 30 };

// 축약형 표현
int[] scores = { 10, 20, 30 };
```
#### 문자 배열
- `문자열`이란 문자를 나열한 것을 의미한다. 
- `char` 타입 요소를 저장하는 배열로, 각 문자는 작은 따옴표(`'`)로 감싼다.
```cs
// 문자 배열 선언 및 초기화
char[] letters = new char[] { 'U', 'n', 'i', 't', 'y' }

// 문자 배열을 string으로 변환
string word = new string(letters); // "Unity"

// string을 char 배열로 변환
char charArray = word.ToCharArray();
```

#### 세부 내용(C#)

##### 자료형 크기(단위는 Byte)
- `int` : **4**
- `char` : **2** (C#은 UTF-16 유니코드를 사용한다.)
- `string` : **가변**(참조 타입)
	- 힙 영역에 할당
	- 객체 헤더 정보(8 ~ 16) + 문자열 길이(4) + (문자 수 * 2) + 널 종료 문자로 구성된다.

##### 배열의 메모리 할당 원리
- C#에서 **배열은 참조 타입**이며, **힙 영역에 연속된 메모리 공간으로 들어간다.**

1. 값 타입 배열 - `int[], char[]`  등
	- 실제 데이터가 메모리에 순서대로 들어간다. 
	- `int[3]`이라면 12바이트, `char[3]`이라면 6바이트의 연속된 공간이 할당된다.

2. 참조 타입 배열 - `string[]`, `GameObject[]` 등
	- 배열의 메모리 공간에는 객체를 가리키는 메모리 주소인 포인터가 저장된다.
		- 64비트 기준 포인터 크기는 8 바이트.
	- `string[3]` 배열 생성 시 8 바이트 주소값 3개가 연속으로 들어가고, 각 주소는 힙의 서로 다른 위치에 있는 실제 `string` 객체를 가리킨다.

#### C#에서 배열 구현해보기
- 배열의 핵심
	- 크기 지정
	- 인덱스를 통한 접근(`[] 연산자`)
	- 경계 검사`Index Out of Range`

```cs
using System;
using System.Runtime.InteropServices;

public class UnsafeIntArray: IDisposable
{
	private IntPtr _memoryPtr; // 할당된 메모리의 시작 주소 포인터
	public int Length { get; me; private set; }
	
	public UnsafeIntArray(int length) 
	{
		Length = length; 
		// int 크기(4 바이트) * 길이만큼 C++의 malloc처럼 비관리 메모리 할당
		int sizeInBytes = sizeof(int) * length;
		_memoryPtr = Marshal.AllocHGlobal(sizeInBytes);
	}
	
	public int this[int index]
	{
	
	}
}
```
