## 개념
- 함수가 자기 자신을 호출하여 순환하여 수행되는 것. 
- 문제에 따라 전체를 한 번에 해결하기보다 **같은 유형의 하위 작업으로 분할해서 해결하는 방법이 효과적일 수 있는데, 이때 재귀호출을 사용**한다. 
- `베이스케이스` : 한 번에 해결할 수 있을 정도로 작업 단위가 충분히 작아진 상태

## 예시 1 : 팩토리얼 함수
```cs
// 반복문 사용
public int IterFactorial(int n) 
{
	int x = 1;
	for(int i = 1 ; i <= n; i ++) 
	{
		x *= i;
	}
	return x;
}

// 재귀함수 사용
public int RecursiveFactorial(int n) 
{
	// n이 0이하일 때는 전부 1로 처리한다는 듯
	if (n <= 1) return 1;
	return n * RecursiveFactorial(n - 1);
}
```

- 추가 팁
1. 코드상으로는 재귀함수가 훨씬 짧지만, 스택 프레임 측면에서는 반복문이 더 유리하다.
	- N이 클 경우 재귀함수는 스택 오버플로우가 발생할 수 있음.
2. `int`는 `13!`을 초과하면 오버플로우가 발생한다. `long`으로 바꾸는 걸 권장

## 예시 2. 하노이 탑
### 문제 정의
- 3개의 기둥 A, B, C
- 3개의 원반이 위부터 1, 2, 3이 A에 쌓여 있다.
	- 큰 숫자는 작은 숫자 위에 올 수 없다. 
- A에 있는 원반 3개를 C로 옮기시오

### 문제 해결 과정
- 초기 상태
 - **`hanoi` : 원반 3개를 시작봉 A에서 중간봉 B를 거쳐 목적봉 C로 옮기는 함수로 정의** 한다.
	 - 이 정의 부분이 매우 중요함.
```
hanoi(3, 'A', 'B', 'C');
```

- 과정 하나하나를 추적해보면
	- 1번을 A -> C로 옮김
	- 2번을 A -> B로 옮김
	- 1번을 C -> B로 옮김

- 위 과정을 마치면 `A에 3`, `B에 1, 2`, `C에 아무 것도 놓이지 않은 상태`가 된다.
- 이 때, 위 3개의 과정은 원반 2개를 시작봉 A에서 중간봉 C를 거쳐 목적봉 B로 옮긴 게 됐다.
- 그래서 아래처럼 정의할 수 있음.
```
hanoi(2, 'A', 'C', 'B');
```

- 그러면 'A'에 있는 3을 C로 옮길 수 있게 된다.
```
hanoi(1, 'A', 'B', 'C');
```
> 원반이 1개이므로 베이스케이스이기도 하다.

- 지금까지의 과정을 봤을 때, 나머지 과정도 구체적으로 몰라도 아래처럼 정의할 수 있다.
```
hanoi(2, 'B', 'A', 'C');
```
### 일반화
- 따라서, 위 문제는 아래처럼 변수를 정의하면 
	- 옮겨야 하는 원반의 갯수 : `n`
	- 시작봉 : `start`
	- 중간봉 : `mid`
	- 목적봉 : `end`

```
hanoi(n, start, mid, end)는 아래 3개의 문제로 분할할 수 있게 된다는 것이다.
hanoi(n-1, start, end, mid)
hanoi(1, start, mid, end) <-- 이건 재귀호출의 대상이 아님
hanoi(n-1, mid, start, end)
```
> **"이런 식으로 문제를 분할할 수 있다"는 게 포인트**임!

- C# 코드로 나타내면 이렇게 됨.
```cs
void Hanoi(int n, char start, char mid, char end)
{
	// 기저 조건
	if (n == 1) return;

	hanoi(n-1, start, end, mid);
	hanoi(n-1, mid, start, end);
}
```
- 하노이의 탑의 시간 복잡도는 $O(2^{N})$이다.  원판이 늘어날 때마다 작업량이 2배씩 증가한다.

### 중간에 오해한 게 있는 거 같아서 좀 더 파봄
- 중간에 1을 옮기는 부분을 `n-2`라고 오해한 부분이 있었다. 
- 하노이의 탑은 이렇게 생각하면 됨.
```
n개의 원반 중, n-1개의 원반을 하나의 덩어리로 본다.

1. n-1개의 원반을 시작봉->중간봉으로 이동시킴
2. 1개의 원반을 목적봉으로 이동시킴 (베이스 케이스)
3. n-1개의 원반을 중간봉->목적봉으로 이동시킴
```
