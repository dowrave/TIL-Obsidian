
## 타입Type
- 설계도, 정의 개념.
- 컴퓨터에게 **이 데이터가 사용하는 메모리, 어떤 값과 기능을 갖는지 알려주는 규격**이다.
```cs
public class Monster
{
	public int hp = 100;
	public string name;
	public void Attack() { ... }
}
```

- `코드(Code)` 영역에 식별 정보만 존재한다.

## 객체Object
- **타입을 바탕으로 메모리에 실제 공간을 확보하여 구체화된 데이터**이다. 
- **`인스턴스`** 라고도 부른다.
```cs
Monster slime1 = new Monster();
slime2.name = "파란 슬라임";

Monster slime2 = new Monster();
slime2.name = "빨간 슬라임";
```

- `힙(Heap)` 영역에 실제 데이터를 갖고 존재한다. 

## 질문

### 파이썬에서의 10과 C#에서의 10의 차이점

#### C#에서의 10
- `int x = 10`을 실행하면, 메모리에는 오직 숫자 10을 뜻하는 이진수 4바이트만 존재한다.
	- 메모리 상태(Stack) : `[00 00 00 0A]`
		- 각 숫자가 4Bit라고 생각하면 이해하기 쉬움. 이런 표기법엔 익숙해져야 할 듯..
	- 다른 부가 정보가 없다.
	- CPU는 이 정보를 빠르게 읽어서 바로 사칙 연산을 수행할 수 있다.

- 특이사항 : `10.ToString()`처럼 메서드를 호출할 수 있는데, 얘도 객체 아님?
	- C#은 평소에는 값으로 다루다가, `object` 타입을 담거나 메서드를 호출하는 등 객체로서의 기능이 필요한 시점에만 일시적으로 힙에 넣어 객체로 변환한다.
	- 이것도 [[CS - 박싱과 언박싱]] 개념.
#### Python에서의 10
- `x = 10`을 실행하면, `C`로 된 `PyObject`라는 구조체가 힙 메모리에 만들어진다.
- 메모리 상태 (Heap)
	- 참조 횟수 (Reference Count) : 8 Byte
	- 타입 정보 (PyTypeObject 포인터) : 8 Byte
	- 실제 값(10) : 8 Byte 이상
	- 숫자 10 하나를 담는 데 약 28 Byte 이상의 메모리를 사용한다.
- 즉, **변수 `x`** 는 숫자 `10`을 직접 갖는 게 아니라, **힙 메모리에 있는 거대한 포장지의 주소값을 가리킨다.**
