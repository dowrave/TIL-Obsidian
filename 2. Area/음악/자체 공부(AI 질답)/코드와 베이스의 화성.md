#음악

기본적으로 **베이스는 코드의 구성음을 중심으로 움직이는 게 안정적**이다.
동시에, 베이스는 **화성의 근음을 명확하게 제시하고 코드의 진행 방향과 성격을 결정**하는 역할도 한다.

## 1. **코드의 근음을 베이스**로
- C Major라면 C-E-G. 그중에서도 C를 치면 근음을 강조하므로 안정적인 느낌을 준다.

## 2. 베이스는 반드시 코드의 구성음이어야 하나? : X

- 크게 3가지 경우로 나눌 수 있다.

### 1. 코드 구성음 사용

### 2. 경과음(Passing Tone) 사용
- 예를 들어 C -> F로 이동한다고 하면, C 코드 안에서 베이스는 C -> **D -> E**의 움직임을 서서히 가져간 다음 코드의 변화와 함께 F로 이동할 수 있다. 이때 D와 E를 경과음이라고 한다.
- 여기서 E는 코드 구성음이지만, 동시에 경과음이기도 하다.

### 3. 코드와 다른 베이스음 사용 : Slash Chord
- 재즈, R&B, 팝 등에서 쓰이는 방식.
- C 코드에 D를 베이스로 치면 `C/D`라는 형태가 된다. 새로운 화성적인 색채가 될 수 있다.
	- 전위(보이싱)와 비교하면 `/` 뒤에 오는 음이 코드의 구성음이 아니라는 차이는 있겠음.

## 3. 추천 접근 순서
1. 코드의 근음을 베이스로 
2. 코드 구성음으로 베이스 구성 : 코드의 안정감과 변화 표현
3. 순차 진행으로 연결 : 부드러운 베이스라인 구성
4. 경과음, 접근음 활용 : 다음 코드로 자연스럽게 연결
5. 비화성음 활용 : 긴장감, 색채 부여

## 4. 베이스는 화성 진행의 느낌을 크게 바꿀 수 있다.
- 코드가 똑같이 C->F->G->C로 진행된다고 해도

- 베이스 구성에 따라 곡의 분위기가 크게 바뀐다.
	- C->F->G->C(근음)
	- C->A->G->E(베이스의 선율적 움직임)
	- C->F/A->G/B->C(베이스의 상행)
