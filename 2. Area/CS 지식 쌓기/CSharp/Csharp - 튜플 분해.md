#Csharp 


```cs
(nodes[a], nodes[b]) = (nodes[b], nodes[a]);
```

라는 코드를 볼 때, 컴파일러는 2단계로 나눠서 작업한다.
1. **오른쪽부터 평가** - `nodes[b]`, `nodes[a]`라는 값 각각을 컴파일러가 만든 임시 변수에 만들어둔다.
2. 왼쪽에 순서대로 임시 값들을 대입한다.

코드로 보면 이런 모양임.
```cs
T temp1 = nodes[b];
T temp2 = nodes[a];
nodes[a] = temp1;
nodes[b] = temp2;
```

`(T, T)` 형태의 튜플은 별도의 클래스 할당(힙 할당) 없이 `ValueTuple`이라는 값 타입으로 처리되며, 이런 패턴에서는 컴파일러가 튜플 객체를 만들지 않고 지역 변수 대입으로 처리해버린다.


---
>[!question]
>튜플도 원래는 참조 타입인가?

- **C#에는 두 종류의 튜플**이 있다. 

1. `System.Tuple<T1, T2>` - 클래스, 참조 타입
```cs
Tuple<int, int> t = new Tuple<int, int>(1, 2);
```
- .NET 4.0(2010년)에 처음 나온 것으로, `class`로 정의되어 있어서 힙에 할당되는 참조 타입이다. 
- `Tuple`을 하나 만들 때마다 GC가 관리해야 할 객체가 생기는 개념이라서 스왑 같이 자주 쓰이는 작업에는 비용이 아깝다.


2. `System.ValueTuple<T1, T2>` - 구조체, 값 타입
```cs
(int, int) t = (1, 2);
```
- C# 7(2017년)부터 나온 튜플 리터럴 문법 `(a, b)`는 기본적으로 `ValueTuple`을 쓴다.
- 구조체라서 값 타입.
