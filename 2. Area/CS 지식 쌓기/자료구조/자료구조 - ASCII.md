- `American Standard Code for Information Interchange`는 7비트를 사용하며, 상위 3비트의 존 비트와 하위 4비트의 숫자 비트로 구성된다. 
```
A B C ㅁㅁㅁㅁ
```

- **영문, 숫자, 특수문자**를 표현한다.

- 7비트 = **128개 문자**를 표현한다.

- `제어 문자`가 포함되어 있다.
	- 지금도 자주 쓰는 것들
		- `LF` : Line Feed, `\n`
		- `CR` : Carriage Return, `\r`, 커서를 줄 맨 앞으로 이동
		- `TAB` : `\t`, 
		- `NUL` : `\0`, 문자열 종료 (C에서 매우 중요)
		- `ESC`
	- 초기엔 터미널과 프린터를 제어하기 위해 사용됐다.

- **숫자와 알파벳이 연속적으로 배치**되어 있다.
	- `0 ~ 9` : 48 ~ 57
	- `:, ;, <, =, >, ?, @` : 58 ~ 64
	- `A ~ Z` : 65 ~ 90
	- `a ~ z` : 91 ~ 122
	- 소문자와 대문자의 차이는 `32(0x20)`이다. 

- 현대 컴퓨터에서는 **보통 1바이트에 저장**된다.

- 유니코드의 앞부분과 호환된다.
	- `UTF-8, UTF-16` 등에서도 아스키 128개 문자의 값은 그대로 유지된다.
	- 즉, `A`는 `UTF-8`에서도 `65(0x41)`이다.

> "메모리의 기본 저장 단위는 1바이트이다." 맞는 표현일까?
- 표현을 정리할 필요가 있다.
	- 메모리의 기본 저장 단위는 1바이트이다.
	- 메모리는 1바이트 단위로 주소가 할당된다.
	- 정보의 최소 표현 단위는 비트다.
- 일부 특수한 하드웨어에서는 바이트가 아닌 다른 크기로 주소를 지정하는 경우도 있었다고 한다. 근데 그냥 이렇게 알고 계셈.
