- 소수점이 직접 표현되지 않고, 정수부와 실수부의 위치를 정의한다.
- 소수점 위치가 항상 고정되는 `고정소수점` 방식과 변하는 `부동소수점` 방식이 있다.

## 고정소수점 표현 방식
- 소수점이 항상 최상위 비트의 왼쪽 밖에 고정되어 있거나, 최하위 비트의 오른쪽 밖에 고정되어 있다고 가정한다. 단순히 해당 비트의 앞뒤로 `0.xxxxxxxx`이거나 `xxxxxxxx.0`이므로, 정수 표현과 같다.

## 부동소수점 표현 방식
- $213 = 0.213 \times 10^{3}$ 같은 과학적 표현 방식을 사용한다.
	- 소수부(0.213), 밑수(10), 지수(3)

- 현재는 **IEEE 754 표준 표기 방식**에 따른 부동소수점 표현 형식을 사용한다.
- 표현 범위를 기준으로 아래처럼 나뉜다.
	- `단정도Single Precision 부동소수점 표현` : 4바이트
	- `배정도Double Precision 부동소수점 표현` : 8바이트

- 부호, 지수, 가수의 세 영역에 대해 비트를 할당한다.
```
단정도 : 부호(1) | 지수(8) | 가수(23)
배정도 : 부호(1) | 지수(11) | 가수(52)
```

### 예시 : `100010.101`을 IEEE 754 표준에 따라 부동소수점으로 전환하기
1. **정규화** : 정수부가 1이 되도록 소수점을 이동해 과학적 표기로 전환한다.
$$
1.00010101 \times 2^{5}
$$
2. **부호** : 양수는 0, 음수는 1을 저장한다.
3. **가수부** : 정규화하면 정수부는 항상 1이 되므로, 소수부(00010101)만 앞부터 저장한다. 뒤의 나머지는 0.
4. **지수부** 
	- **부호 없는 정수**로 저장한다.
	- 정규화해서 구한 지수와 `바이어스`를 더한 값을 저장한다. 
	- **`바이어스`란, 지수의 부호를 표현하기 위해 사용하는 값**이다. 
		- **단정도에서는 127**을 사용 - 지수 5 + 127 = 132 = 10000000100(2)
		- **배정도에서는 1023**을 사용 - 지수 5 + 1023 = 1028 = 10000000100(2)
		- 지수 비트에 따라 바이어스 값은 `2^(n-1)-1`이다.
			- 지수 범위를 대칭적으로 쓸 수 있기 때문에 이 값을 쓴다. 
			- 예시 ) 단정도의 지수부는 8비트, 0 ~ 255인데, `0(0, 서브노멀), 255(무한)`을 제외한 1~254를 실제 지수에 사용한다. 이 때 들어가는 지수값은 `1 = -126, 127 = 0, 254 = 127`이 되어 음수와 양수를 균형 있게 표현할 수 있다.

- 위 과정을 거치면 
```
(부호 지수 가수)
- 단정도 : 0 10000100(8비트) 000101010000...0(23비트)
- 배정도 : 0 1000000100(11비트) 00010101000...0(52비트)
```
