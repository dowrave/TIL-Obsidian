#자료구조
## 1. 자료구조의 이해
### 1. 자료구조의 개념
- `자료구조` : 컴퓨터 속 자료를 효율적으로 표현하고 저장하고 처리할 수 있도록 정리하는 것

- 왜 자료구조를 공부해야 하는가?
- 문제 해결 단계
	- 문제 도출 
		- **문제 정의**
	- 문제 변환
		1. 처리 **방식** 결정 -> **알고리즘** 작성
		2. 처리 **대상** 결정 -> **자료 정의**
		3. 1+2 = 프로그램 작성
	- 실행 (컴퓨터)
		- 프로그램 번역 및 실행
		- 실행 결과
	- 결과
		- 문제 해답

- 문제 정의 : 문제를 더 효율적이고 효과적으로 해결하기 위해 문제를 정의해야 하고
- 문제 변환 : 처리 방식을 결정해 알고리즘을 작성하고 처리 대상을 결정한 뒤 그에 대한 자료를 정의해야 함 

이 두 과정에서 자료구조에 대한 개념을 이해하고 활용하는 능력이 필요하다. 

### 2. 자료구조의 분류

- 단순 구조  
	- 정수
	- 실수
	- 문자
	- 문자열
- 선형 구조(현재와 다음 자료 사이의 관계가 1:1)
	- 순차 리스트
	- 연결 리스트
		- 단순 연결 리스트
		- 이중 연결 리스트
		- 원형 연결 리스트
	- 스택
	- 큐
	- 데크
- 비선형 구조(현재와 다음 자료 사이의 관계가 1:多 혹은 多:多)
	- 트리
		- 일반 트리
		- 이진 트리
	- 그래프
		- 방향 그래프
		- 무방향 그래프
- 파일 구조
	- 순차 파일
	- 색인 파일
	- 직접 파일

이외에도 `정렬`과 `검색`을 다룬다. 
## 2. 자료의 표현

### 1. 컴퓨터에서의 자료 표현
- **1과 0으로 된 2진수 코드를 사용**한다. 
- **`비트bit`** : 2진수 한 자리인 1이나 0을 표현하는 단위
	- n비트는 $2^n$ 개의 상태를 표현할 수 있다.
- **`바이트byte`** : 8비트 그룹
- `니블Nibble` : 4비트 그룹

### 2. 수치 자료의 표현
- 2진수 형태를 10진수로 쉽게 해석할 수 있도록 만든 `존Zone` 형식과 `팩Pack` 형식이 있다.
